‎# Mon Portfolio Personnel 🚀
‎
‎Bienvenue sur le dépôt de mon portfolio ! Ce projet est une présentation de mon parcours, de mes compétences et de mes réalisations en tant que futur développeur.
‎
‎## 🛠️ Technologies utilisées
‎* **HTML5** : Pour la structure du site.
‎* **CSS3** : Pour la mise en page et le design (Responsive Design).
‎* **JavaScript** : Pour l'interactivité.
‎
‎## 📂 Structure du projet
‎Le projet est composé de plusieurs sections :
‎- **Accueil** : Présentation générale.
‎- **À propos** : Détails sur mon parcours académique.
‎- **Compétences** : Liste de mes outils et langages maîtrisés.
‎- **Contact** : Formulaire pour me joindre.
